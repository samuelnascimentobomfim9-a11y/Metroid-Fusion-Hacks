## Como aplicar/usar este patch

- Pesquise pelo "Rom Patcher JS" ou "Hack64 Web Patcher"
- Obtenha um arquivo ROM do *Metroid Fusion [USA]* ou *Metroid Zero Mission [USA]* limpo e não modificado (não funciona com a versão Europa/Japonesa)
- Coloque a ROM do *Metroid Fusion [USA]* ou *Metroid Zero Mission [USA]*, na Rom File e o patch BPS no patch
- Após colocar as roms no lugar correto, clique em "Apply Patch"
- Baixe um emulador de GBA
  - Windows: Após a instalação, localize o emulador e clique duas vezes nele (no arquivo exe).
  - Mobile: Clique uma vez no apk ou app para abrir
- Abra a rom. Se você aplicou o patch corretamente, o jogo deve carregar.
  - Nota: Procure informações de como abrir o arquivo com o desenvolvedor do emulador.
